All the bird photo pages are generated from one data file, assets/data/photos.json, by scripts/build_site.py.

Don't edit the generated pages by hand: the next build overwrites them. On index.html only the photo grid and the menu are generated; the rest of that page can be edited normally. The top menu is also refreshed on the hand-written pages.

Photos live in assets/img/gallery/<species>/, e.g. assets/img/gallery/greater-coucal/greater_coucal5.jpg.

Adding new photos

Requires a Mac (the script uses the built-in sips and mdls tools) and Python 3.

  1. Name each photo after the species plus a number, the way existing files are named: greater_coucal8.jpg, black_kite7.jpg. Pick the next unused number for that species.
  2. In Terminal, from the repository folder, run:
python3 scripts/add_photos.py ~/path/to/greater_coucal8.jpg ~/path/to/black_kite7.jpg \
    --location "Rabindra Sarobar, Kolkata, India" --home

For each photo the script:

  1. works out the species from the file name (greater_coucal8.jpg → Greater Coucal);
  2. resizes it to 1600 px on the long edge and saves it in the species folder (it never overwrites an existing photo);
  3. writes the caption as species, location and month/year, e.g. “Greater Coucal, Rabindra Sarobar, Kolkata, India, Nov 2026” (the date comes from the photo's capture date);
  4. with --home, adds the photo to the top of the home page (portraits go to the portrait block at the bottom, uncropped);
  5. rebuilds every page: the group page, species.html, the overview counts and the home page.

Options

OptionWhat it does
--location "..."Place to put in the caption. Leave it out to caption with just species and date.
--homeAlso feature the photos on the home page.
--group <group>Required for the first photo of a new species: which bird group it belongs to. Without it the script stops and lists the group names: raptors, hummingbirds, waders, waterbirds, woodpeckers, corvids, doves-parrots, finches, orioles, songbirds.
--name "..."Display name for a new species, when the file name can't spell it, e.g. --name "Blyth's Paradise Flycatcher".
--dry-runShow where each photo would go and its caption, without changing anything.

Example for a new species:

python3 scripts/add_photos.py ~/path/to/blyth_paradise_flycatcher3.jpg \
    --location "Rabindra Sarobar, Kolkata, India" \
    --group songbirds --name "Blyth's Paradise Flycatcher"

Fine-tuning by hand

Edit assets/data/photos.json, then rebuild:

python3 scripts/build_site.py

What you can change there:

  • Captions: the caption of a photo in photos.
  • Crop of a portrait photo: on the group pages and species.html, every tile is 4:3, so portrait photos are cropped. Add "crop": "12%" to a photo to move the visible part toward the top (lower % = higher up) so the bird's head stays in view. The full photo always opens when clicked.
  • Home page: the home list, in display order. A plain file name shows portraits full size in the portrait block at the bottom; {"file": "...", "fill": true} crops a portrait to 4:3 among the landscape photos at the top.
  • Bird groups: the groups list sets the group order, titles and descriptions. Add "cover": "<species>/<file>.jpg" to choose the photo on a group's overview card (otherwise the first landscape photo featured on the home page is used).
  • Moving a species to another group: change its group in species.

If a photo is in a species folder but missing from photos.json, the build still publishes it (captioned with just the species name) and prints a note, so nothing silently disappears.
